# 开发路线图

> 本文档描述 MT管理器开源版 的开发计划和里程碑。

## 版本规划

### v0.1.0 - MVP 核心框架 (预计 3-4 个月)

**目标**：实现基础双窗口文件管理器

- [ ] 项目基础架构搭建
  - [ ] Gradle 多模块项目结构
  - [ ] CI/CD 流水线（GitHub Actions）
  - [ ] 代码质量工具（Detekt、ktlint）
  - [ ] 基础 UI 框架（Jetpack Compose + RecyclerView 混合）

- [ ] 双窗口文件管理核心
  - [ ] DualPaneLayout 实现
  - [ ] 文件列表渲染（列表/网格/详细视图）
  - [ ] 基础文件操作（复制/移动/删除/重命名）
  - [ ] 路径导航栏（面包屑 + 路径编辑）
  - [ ] 文件选择和多选模式

- [ ] 基础手势支持
  - [ ] 长按选择
  - [ ] 下拉刷新
  - [ ] 边缘侧滑（书签/历史）

- [ ] 存储权限适配
  - [ ] Android 8-10 传统权限
  - [ ] Android 11+ Scoped Storage 适配
  - [ ] Android 13+ 细分媒体权限

- [ ] 内置基础编辑器
  - [ ] 文本查看器（只读）
  - [ ] 图片查看器
  - [ ] 十六进制查看器（只读）

**技术债务**：
- 暂不支持压缩包内编辑
- 暂不支持 Root 访问
- 暂不支持远程存储
- UI 动画和过渡效果简化

- [ ] 文件属性

## 开发资源需求

### 人力

| 角色 | 人数 | 职责 |
|------|------|------|
| 项目维护者 | 1-2 | 架构设计、代码审查、发布管理 |
| Android 开发者 | 2-3 | 核心功能开发 |
| UI/UX 设计师 | 1 | 界面设计、交互优化 |
| 文档维护者 | 1 | 技术文档、用户手册 |
| 测试工程师 | 1 | 测试用例、自动化测试 |

### 基础设施

- GitHub 仓库（代码托管、Issue 跟踪）

## 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 开发者时间不足 | 进度延迟 | 保持MVP优先，接受功能裁剪 |
| 法律风险 | 项目下架 | 严格的功能限制，完善的免责声明 |
| 许可证冲突 | 代码重构 | 早期规划插件架构，严格代码审查 |
| 社区贡献不足 | 维护困难 | 降低贡献门槛，完善文档 |
| 与MT管理器混淆 | 法律纠纷 | 明确品牌区分，独立名称和标识 |
